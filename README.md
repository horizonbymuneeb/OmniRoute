# omniroute — host wrapper

This branch carries the **VPS-side wrapper** for OmniRoute, not the upstream application
source. Upstream lives on `main` (restored from `diegosouzapw/OmniRoute`).

## What is here

| Path | Purpose |
|---|---|
| `run.sh` | Podman launcher. Runs `docker.io/diegosouzapw/omniroute:latest` on host networking. |
| `run.sh.bak` | Pre-change backup of the launcher. |
| `patches/` | Patched vendored bundles (`open-sse`, `src/shared`) applied over the upstream image. |
| `graphify-out/` | Local AST graph cache for this directory. Safe to delete; regenerated by `graphify update .`. |

## Ports

- HTTP / dashboard / API — `21139`
- Live WebSocket — `21143`

## Service

`omniroute.service` runs `/opt/apps/omniroute/run.sh`.

## Where the real data lives

**Not in this repo.** The 470 MB SQLite database — which holds every provider connection,
including the 56 Antigravity (`agy`) OAuth accounts with their access and refresh tokens —
is stored in the Podman volume:

```
/var/lib/containers/storage/volumes/omniroute-data/_data/storage.sqlite
```

It is deliberately never committed. `runtime/omniroute.env` holds the container
environment and is likewise excluded.

## Secrets

No credentials are committed here. `patches/` were checked for token-shaped strings before
publishing; the only matches were upstream's own redaction regexes and test fixtures.
